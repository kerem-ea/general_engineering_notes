# Half-Cells and Standard Potentials

Only potential *differences* are measurable. All half-cell potentials are referenced to the SHE:

$$E_{\text{cell}} = E_{\text{cathode}} - E_{\text{anode}}$$

## Standard Hydrogen Electrode (SHE)

$$2\mathrm{H^+}(aq) + 2\mathrm{e^-} \rightleftharpoons \mathrm{H_2}(g) \quad E^\circ \equiv 0.000\text{ V}$$

Standard conditions: $a_{\mathrm{H^+}} = 1\text{ M}$, $p_{\mathrm{H_2}} = 1\text{ bar}$, $T = 298\text{ K}$, Pt catalyst.

## Activity

| Phase | Activity |
|---|---|
| Pure solid / liquid | $a = 1$ |
| Gas | $a = p_i / \text{bar}$ |
| Solute | $a = c_i / \text{M}$ |

## Standard Reduction Potentials ($25{}^\circ\text{C}$)

| Half-reaction | $E^\circ$ (V) |
|---|---|
| $\mathrm{Li^+ + e^- \to Li}$ | $-3.01$ |
| $\mathrm{Zn^{2+} + 2e^- \to Zn}$ | $-0.76$ |
| $\mathbf{2H^+ + 2e^- \to H_2}$ | $\mathbf{0.00}$ |
| $\mathrm{Cu^{2+} + 2e^- \to Cu}$ | $+0.34$ |
| $\mathrm{Ag^+ + e^- \to Ag}$ | $+0.80$ |
| $\mathbf{O_2 + 4H^+ + 4e^- \to 2H_2O}$ | $\mathbf{+1.23}$ |
| $\mathrm{F_2 + 2e^- \to 2F^-}$ | $+2.87$ |

## Examples

**Zn-Ag battery:**
$$E^\circ = 0.80 - (-0.76) = 1.56\text{ V}$$

**$\mathrm{H_2}$-$\mathrm{O_2}$ fuel cell:**
$$E^\circ = 1.23 - 0.00 = 1.23\text{ V}$$
