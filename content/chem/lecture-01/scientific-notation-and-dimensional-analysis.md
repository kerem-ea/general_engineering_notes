# Scientific Notation and Dimensional Analysis

## Scientific notation

Scientific notation represents a number as

$$
a \times 10^n
$$

where \(1 \leq |a| < 10\) and \(n\) is an integer.

It is useful for working with very large or very small quantities.

## Dimensional analysis

Dimensional analysis checks that equations and calculations are dimensionally consistent.

Common SI base quantities include:

- Length — metre (m)
- Mass — kilogram (kg)
- Time — second (s)
- Amount of substance — mole (mol)
- Temperature — kelvin (K)
