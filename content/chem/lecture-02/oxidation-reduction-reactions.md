# Oxidation-Reduction Reactions

**Redox (reduction-oxidation) reactions** involve electron transfer and changes in oxidation numbers.

- **Oxidation:** Loss of electrons (oxidation number increases).
- **Reduction:** Gain of electrons (oxidation number decreases).
- *Mnemonic:* **OIL RIG** (Oxidation Is Loss, Reduction Is Gain).

## Agents

| Agent | Function | State Change |
|---|---|---|
| **Reducing agent** | Donates electrons | Is **oxidized** |
| **Oxidizing agent** | Accepts electrons | Is **reduced** |

$$
2Na(s) + Cl_2(g) \rightarrow 2NaCl(s)
$$
- $Na \rightarrow Na^+ + e^-$ (oxidation; $Na$ is reducing agent)
- $Cl_2 + 2e^- \rightarrow 2Cl^-$ (reduction; $Cl_2$ is oxidizing agent)

## Oxidation Number Rules

1. **Free elements:** $0$ (e.g., $Na$, $O_2$, $Cl_2 = 0$).
2. **Monatomic ions:** Equals ionic charge (e.g., $Na^+ = +1$, $Cl^- = -1$).
3. **Common values:**
   - **$F$:** $-1$ in all compounds.
   - **$O$:** $-2$ (except $-1$ in peroxides).
   - **$H$:** $+1$ with nonmetals, $-1$ with metals (hydrides).
   - **Halogens:** usually $-1$ (except when bonded to more electronegative atoms).
4. **Sums:**
   - Neutral compound: $\sum \text{oxidation states} = 0$
   - Polyatomic ion: $\sum \text{oxidation states} = \text{ion charge}$

*(Note: ionic charge is written $2+$; oxidation number is written $+2$)*
