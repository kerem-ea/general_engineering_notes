# Types of Reactions

There are multiple types of reactions. The common types of reactions are:

1. Synthesis
2. Decomposition
3. Single Displacement
4. Double Displacement 
5. Combustion

## Synthesis

A synthesis reaction is a reaction where:

$$A + B \rightarrow AB$$

## Decomposition 

A decomposition reaction is a reaction where:

$$AB \rightarrow A + B$$

## Single Displacement

A single displacement reaction is a reaction where:

$$A + BC \rightarrow AC + B$$

## Double Displacement

A double displacement reaction is a reaction where:

$$AB + CD \rightarrow AD + CB$$

## Combustion

A (complete) combustion reaction is a reaction where:

$$C_xH_y + O_2 \rightarrow CO_2 + H_2O$$
