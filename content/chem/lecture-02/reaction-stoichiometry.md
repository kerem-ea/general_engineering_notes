# Stoichiometry

**Stoichiometry** relates the quantitative amounts of reactants and products based on the **mole ratios** established by a balanced chemical equation.

## Mole Ratios

For the reaction:
$$aA + bB \rightarrow cC + dD$$

The stoichiometric mole ratio between species $A$ and $C$ is $\frac{c}{a}$:
$$n_C = n_A \times \frac{c}{a}$$

## Conversion Pathway

$$
\text{Mass } A \xrightarrow{\div M_A} \text{Moles } A \xrightarrow{\times \frac{c}{a}} \text{Moles } C \xrightarrow{\times M_C} \text{Mass } C
$$

*(Convert between particles and moles via $N_A = 6.022 \times 10^{23}\ \text{mol}^{-1}$).*

## Calculation Example

Given $N_2(g) + 3H_2(g) \rightarrow 2NH_3(g)$, mass of $NH_3$ produced from $10.0\text{ g } H_2$:

$$
m_{NH_3} = 10.0 \text{ g } H_2 \times \frac{1 \text{ mol } H_2}{2.016 \text{ g } H_2} \times \frac{2 \text{ mol } NH_3}{3 \text{ mol } H_2} \times \frac{17.03 \text{ g } NH_3}{1 \text{ mol } NH_3} = 56.3 \text{ g } NH_3
$$
